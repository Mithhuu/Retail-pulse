# 📊 Retail Pulse – Retail Data Analysis Project

## About the Project

Retail Pulse is a beginner-friendly data analysis project that explores retail sales data to identify sales trends, profit performance, product performance and regional business insights.

The main objective is to understand business performance using Python and data visualization.

## Objectives

* Analyse overall retail sales and profit.
* Identify the best-performing product categories.
* Understand regional sales performance.
* Analyse monthly and yearly sales trends.
* Identify profitable and loss-making products.
* Generate useful business insights.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab
* GitHub

## Dataset

Sample Superstore Dataset.

The dataset contains retail transaction information, including sales, profit, products, customers, regions and order dates.

## Key Performance Indicators (KPIs)

| KPI                 |        Result |
| ------------------- | ------------: |
| Total Sales         | $2,297,200.86 |
| Total Profit        |   $286,397.02 |
| Total Quantity Sold |        37,873 |
| Profit Margin       |        12.47% |

## Key Business Insights

1. Technology is the highest-performing category in sales and profit.
2. The West region generates the highest sales and profit.
3. Copiers generate the highest profit among subcategories.
4. Tables are the biggest loss-making subcategory.
5. The Consumer segment is the most profitable customer segment.
6. Excessive discounts can reduce business profitability.
